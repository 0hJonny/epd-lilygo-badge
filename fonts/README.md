# Font

`main/ui_font_jp.otf` is a subset of Noto Sans JP containing only the glyphs this firmware can render. It is generated, not tracked in git — build it before the first compile.

A character absent from the subset renders as blank space. There is no fallback and no warning, so if a label goes missing on the panel, check here first.

## Building

```bash
pip install fonttools brotli
python3 build_font.py NotoSansJP-Light.ttf
cd .. && idf.py build
```

The script scans `ui_strings.h`, `socials.h` and `user_profile.h` for string literals, merges them with `glyphs.txt`, and writes the subset to `../main/ui_font_jp.otf`.

Literals behind an inactive `UI_LANG` branch are included, so switching languages later does not require another subset.

### When to rerun

- Adding or editing a link label or monogram in `socials.h`
- Editing `PHOTO_SIGN` or `STATUS_BADGE` in `user_profile.h`
- Adding a language to `ui_strings.h`

URLs are skipped — they are encoded into QR codes, never drawn with the font.

### Inspecting the glyph set

```bash
python3 collect_glyphs.py
```

Prints a per-Unicode-block breakdown and writes `glyphs_merged.txt`. Useful for answering "why did the subset grow" without running fontTools. Anything reported outside the expected blocks usually means `glyphs.txt` picked up something unintended.

## Source font

https://fonts.google.com/noto/specimen/Noto+Sans+JP

Any weight works; Light (300) is closest to the DemiLight this project started from.

Do not take the font from third-party repositories. Noto CJK shipped under Apache 2.0 in early releases and OFL 1.1 later, and a file without an accompanying license leaves the terms unknown.

## Files

| File                     | Tracked | Purpose                                                 |
| ------------------------ | ------- | ------------------------------------------------------- |
| `build_font.py`          | yes     | Collects glyphs and produces the subset                 |
| `collect_glyphs.py`      | yes     | Glyph list with per-block breakdown, no font output     |
| `glyphs.txt`             | yes     | Base set: ASCII, kana, punctuation, common kanji        |
| `OFL.txt`                | yes     | License. Must accompany redistribution                  |
| `glyphs_merged.txt`      | no      | Generated by `collect_glyphs.py`                        |
| `../main/ui_font_jp.otf` | yes     | Generated by `build_font.py`, committed for convenience |
| `NotoSansJP-Light.ttf`   | yes     | Source font, unmodified, OFL 1.1                        |

`glyphs.txt` holds a few hundred frequently used kanji, not the full jōyō set. The script adds whatever the headers actually use on top, so the base set only matters for characters a fork might introduce.

## Output naming

Fixed at `ui_font_jp.otf`. The build derives the asm symbols `_binary_ui_font_jp_otf_start` / `_end` from the filename, so renaming means updating `EMBED_FILES` in `main/CMakeLists.txt`, `embedded_assets.h`, `DEFAULT_OUTPUT` in `build_font.py`, and `.gitignore`. Run `idf.py fullclean` afterwards — stale object files carry the old symbol names.

The extension stays `.otf` regardless of source format. If the input is a `.ttf`, the output carries TrueType outlines under an `.otf` name; `tiny_ttf` reads both.

The name deliberately avoids both `Noto` and `Source`. `build_font.py` also retitles the internal font family to `UI Font JP Subset`; pass `--keep-name` to skip that.

## License

SIL Open Font License 1.1. `OFL.txt` is reproduced verbatim from the upstream release and must not be edited or replaced — condition 2 requires the copyright notice and license text to accompany every copy.

- The declared Reserved Font Name is `Source`, inherited from Adobe Source Han Sans, which Noto Sans CJK derives from. Neither the output filename nor the internal family name uses it, or `Noto`.
- The subset is a Modified Version under OFL terms.
- `build_font.py` preserves the font's `name` table, so the embedded copyright notice survives subsetting. Condition 2 permits the notice to live in machine-readable metadata.
- Condition 5 keeps the font and its derivatives under OFL. It does not affect the firmware source, which is licensed separately — embedding a font in software is explicitly permitted by condition 2.

## Sizing

The application partition is 4 MB (`partitions.csv`) and holds the firmware alongside this font. `build_font.py` warns above 2 MB and prints the delta against the previous build.

A full unsubsetted Noto Sans JP is roughly 5 MB and does not fit without enlarging `factory`. Doing so is viable — about 12 MB of the 16 MB flash is unallocated — and removes the regeneration step entirely, at the cost of 30–60 seconds added to every `idf.py flash`.
